Bu anahtar örnek amaçlıdır; gerçek projelerde Cloud Console’dan oluşturun ve kısıtlamalar ekleyin.

1. Maps JavaScript API

  • İnteraktif haritalar (web/mobile)
  • Marker, polyline, polygon, ground overlay
  • Kullanıcı konumu (HTML5 Geolocation)
  • Harita kontrolleri (zoom, map type, street view)

2. Places API

  • Place Search – telefon, adres, puan, fotoğraf
  • Autocomplete – adres önerileri
  • Place Details – detaylı bilgiler (telefon, saatler, ücret, inceleme)

3. Geocoding API

  • Adres → koordinat (lat/lng)
  • Koordinat → adres (reverse geocoding)

4. Directions API

  • Yol tarifi (yürüyüş, araç, toplu taşıma)
  • Çoklu waypoint, trafik durumu

5. Distance Matrix API

  • Bir noktadan birçok yere mesafe/süre matrisi

6. Roads API

  • GPS trace’i yol üzerine snapping
  • Speed limit bilgisi

7. Time Zone API

  • Koordinatlı saat dilimi (DST dahil)

8. Elevation API

  • Yükseklik (dem) verisi

Maliyet ve Limitler

  • Ücretsiz aylık $200 kredi (tüm API’ler için)
  • Maps JavaScript API: ~$7/1000 yükleme (free tier 28k/ay)
  • Places API: ~$17/1000 istek (Autocomplete daha ucuz)
  • Directions API: ~$5/1000 istek
  • Geocoding: ~$5/1000 istek
  • Kilit: API key’i HTTP referrer ile kısıtla (sadece kendi domainlerin)
  • Kullanım dashboard: Google Cloud Console > APIs & Services

Güvenlik Notları
